# Cloudflare Build Fix

Diese Version enthält `wrangler.jsonc` und `package.json`, damit Cloudflare
`npx wrangler deploy` automatisch als Worker mit Static Assets ausführen kann.

Build command: leer
Deploy command: npx wrangler deploy
Version command: leer
Root directory: leer

Der Worker-Einstieg ist `_worker.js`.
Die statischen Dateien liegen direkt im Repository-Stamm.
